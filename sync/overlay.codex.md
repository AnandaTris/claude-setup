# This host

You are Codex. You write the code here. Claude is the read-only second opinion —
it reviews at gates and never edits on this host. The outside-voice skill is
`gstack-claude`, which wraps `claude -p` with no tools, so Claude can read and
reason but cannot edit.

You do the planning on this host — Claude reviews the plan, it does not write one.

# Heavy work: turn the effort up

Claude Code's lever for big features, audits, migrations, and broad refactors is
`ultracode` — multi-agent workflow orchestration. That does not exist on this
host; you cannot spawn a fleet. Your equivalent is reasoning effort: bump to
`ultra` or `max` for that class of work, and hand the task to Claude when it
genuinely needs parallel agents rather than one deep pass. The default stays
`xhigh` — raise it per task, not permanently.
