# Claude ↔ Codex Config Sync Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Generate `~/.claude/CLAUDE.md` and `~/.codex/AGENTS.md` from one canonical source, share the hook scripts, and close the 17-skill gap, so Claude Code and Codex behave identically except where they must differ.

**Architecture:** `~/.claude/sync/` holds a shared `core.md` template plus a per-host variable file and overlay. `sync.sh` renders `core + overlay` with `{{VAR}}` substitution into each host's instruction file. Hook scripts move to `sync/hooks/` and are symlinked onto both hosts. Settings files are audited, never rewritten.

**Tech Stack:** POSIX sh, `sed`, `jq`, git. No new dependencies.

## Global Constraints

- Canonical source lives at `~/.claude/sync/` — the only versioned dir with a remote.
- `sync.sh` **never** edits `settings.json`, `config.toml`, or `hooks.json`. It audits them and exits nonzero on a gap.
- Generated files carry a `<!-- GENERATED ... -->` first line.
- An unbound `{{VAR}}` surviving into output is a fatal error; write nothing.
- Nothing is deleted. Replaced files move to `~/.claude/backups/`.
- Reciprocal skills `codex` (Claude-only) and `gstack-claude` (Codex-only) are permanently excluded from parity checks.
- Commit messages: conventional commits, subject only, under 72 chars.

- [ ] **Step 3: Write `sync.sh` render subcommand**

```sh
#!/bin/sh
# ~/.claude/sync/sync.sh — canonical config sync for Claude Code and Codex.
set -u
SYNC="$HOME/.claude/sync"
CLAUDE_MD="$HOME/.claude/CLAUDE.md"
CODEX_MD="$HOME/.codex/AGENTS.md"
HDR='<!-- GENERATED by ~/.claude/sync/sync.sh — edit sync/core.md or sync/overlay.*.md, not this file -->'

render() { # <vars> <core> <overlay> <out>
  _v=$1; _c=$2; _o=$3; _out=$4; _tmp=$(mktemp)
  { printf '%s\n\n' "$HDR"; cat "$_c"; printf '\n'; cat "$_o"; } > "$_tmp"
  while IFS='=' read -r k val; do
    case "$k" in ''|\#*) continue ;; esac
    esc=$(printf '%s' "$val" | sed 's/[&|\\]/\\&/g')
    # Portable in-place edit: BSD and GNU sed disagree on -i, so avoid it.
    sed "s|{{$k}}|$esc|g" "$_tmp" > "$_tmp.n" && mv "$_tmp.n" "$_tmp"
  done < "$_v"
  if grep -q '{{[A-Z_]*}}' "$_tmp"; then
    echo "sync: unbound variable(s) in $_c:" >&2
    grep -o '{{[A-Z_]*}}' "$_tmp" | sort -u >&2
    rm -f "$_tmp"; return 1
  fi
  mv "$_tmp" "$_out"
}

case "${1:-}" in
  render) shift; render "$@" ;;
  *) echo "usage: sync.sh render <vars> <core> <overlay> <out>" >&2; exit 2 ;;
esac
```

```sh
check() {
  rc=0; t=$(mktemp -d)
  render "$SYNC/vars.claude" "$SYNC/core.md" "$SYNC/overlay.claude.md" "$t/c.md" || rc=1
  cmp -s "$t/c.md" "$CLAUDE_MD" || { echo "drift: CLAUDE.md differs from core"; rc=1; }
  if [ -f "$CODEX_MD" ]; then
    render "$SYNC/vars.codex" "$SYNC/core.md" "$SYNC/overlay.codex.md" "$t/a.md" || rc=1
    cmp -s "$t/a.md" "$CODEX_MD" || { echo "drift: AGENTS.md differs from core"; rc=1; }
  fi
  for h in "$HOME/.claude/hooks/block-secret-reads.sh" "$HOME/.codex/hooks/block-secret-reads.sh"; do
    [ -e "$h" ] || continue
    case "$(readlink "$h")" in *sync/hooks/*) ;; *) echo "drift: $h is not linked to sync/hooks"; rc=1;; esac
  done
  grep -q '8x_Internship/Keys' "$HOME/.claude/settings.json" || { echo "audit: settings.json lost Keys deny rules"; rc=1; }
  grep -q 'block-secret-reads' "$HOME/.codex/hooks.json" 2>/dev/null || { echo "audit: codex hooks.json missing guard"; rc=1; }
  for s in $SKILL_GAP; do
    [ -e "$HOME/.claude/skills/$s" ] && [ ! -e "$HOME/.codex/skills/$s" ] && { echo "drift: codex missing skill $s"; rc=1; }
  done
  rm -rf "$t"
  [ "$rc" -eq 0 ] && echo "sync: ok"
  return "$rc"
}
```
